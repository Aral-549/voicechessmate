AUDIO PIPELINE HARDENING

4 Core Pillars of the Speech Output Guarantee

1. V8 Utterance Garbage Retention speech.ts // SET<UTTERANCE>
V8 Engine Bug: Chromium garbage collects JavaScript `SpeechSynthesisUtterance` objects before C++ audio playback completes, causing sudden mid-sentence silence.
Solution: Module-level `activeUtterances: Set` retains references until `onend` or `onerror` handlers fire.
✓ ZERO DROPPED UTTERANCES ON LONG DESCRIPTIONS
2. Chrome IPC Cancel-Speak Race Fix 40ms ASYNC SETTLING
IPC Race Bug: Calling `speechSynthesis.cancel()` immediately followed by `speak()` causes the Chromium browser process to drop the new speak command due to unhandled IPC race.
Solution: Enforces an asynchronous 40ms IPC settling delay between cancel and subsequent speak calls.
✓ 100% RELIABILITY ON RAPID-FIRE MOVE ANNOUNCEMENTS
3. Dual-Path Audio Fallback Coordinator voice-agent.ts // DUAL-PATH
Network Desync Risk: WebSocket streaming PCM audio from cloud voice agents can stutter or fail under network instability.
Solution: `scheduleDualPathSpeech` monitors WebSocket PCM playback. If streaming audio is inactive after 1200ms, it automatically falls back to local client TTS.
✓ CONTINUOUS AUDIO PLAYBACK EVEN OFFLINE
4. Centralized Watchdog & Priority Queue QUEUE // 4-TIER PRIORITY
Zombie Pause Bug: Browser backgrounding often freezes synthesis indefinitely.
Solution: Single non-leaking watchdog monitors queue state and pulses `resume()`. 4-tier queue (`Urgent` > `High` > `Normal` > `Low`) ensures critical moves preempt descriptions.
✓ AUTO-RECOVERY FROM STUCK QUEUES WITHIN 200MS
